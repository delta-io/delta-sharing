# Learning journal 2026-11-24

### 2026-11-24: CI / bot — Recognize both old and new bot logins during a bot-identity rename
**Context:** PR #1064 renamed the engineer bot login; a confirmed reviewer finding noted that the self-reply guard and BOT_LOGINS were switched to only the new login, so if the GitHub App/secrets cutover isn't simultaneous with the merge the old bot's comments stop being filtered and can trigger bot loops.
**Rule:** When renaming a bot identity used in self-reply guards or allow/deny login sets, accept both the old and new logins during the migration window and drop the old one only after the App/secrets cutover is confirmed.
