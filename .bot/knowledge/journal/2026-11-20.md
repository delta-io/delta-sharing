# Learning journal 2026-11-20

### 2026-11-20: Scala client — Don't hold an object monitor across a retry/backoff sleep
**Context:** PR #962 — RandomAccessHttpInputStream's read() and read(buf,off,len) are synchronized, and doStreamRead wraps the read in runWithExponentialBackoff whose Thread.sleep can block up to the 10-minute max retry duration, so the monitor stays held for the entire backoff.
**Rule:** Never place a retry/backoff sleep inside a synchronized method or block, because the thread holds the object monitor for the whole sleep and starves every other caller.

### 2026-11-20: CI / bot — Scrub all sensitive tokens before running agent- or issue-authored code
**Context:** PR #1048 — bot-test.sh removed cloud credentials but left DATABRICKS_TOKEN and GH_TOKEN in the environment while running tests the agent writes from an attacker-controllable issue body, enabling token exfiltration via prompt injection.
**Rule:** Before executing agent- or issue-authored code, unset every sensitive token (model, git/GitHub, and cloud) or run it in a credential-less sandbox, not just the cloud credentials.

### 2026-11-20: Scala tests — Only tag tests that truly need cloud credentials as integrationTest
**Context:** PR #836/#837 — a test was tagged integrationTest even though it did not load a real table, which silently skips it for external contributors who lack tokens in pre-commit.
**Rule:** Reserve the integrationTest tag for tests that genuinely require cloud credentials or real tables, since the tag makes external contributors skip the test in pre-commit.

### 2026-11-20: Python connector — pandas 3 infers microsecond, not nanosecond, timestamp resolution
**Context:** PR #1030 — supporting pandas 3 required a _with_nanosecond_timestamps test helper because pandas 3 infers microsecond resolution for pd.Timestamp where pandas 2 used nanosecond.
**Rule:** When supporting pandas 3, expect pd.Timestamp columns to default to microsecond resolution and normalize timestamp dtype in tests instead of asserting nanosecond.

### 2026-11-20: Python build — Keep internal mirror URLs out of committed public lockfiles
**Context:** PR #913 — the committed uv.lock contained entries pointing at an internal pypi-proxy host unreachable outside the VPN, which breaks resolution for public consumers.
**Rule:** Generate committed public lockfiles against public indexes so no internal-only mirror URLs leak into them or break external dependency resolution.

### 2026-11-20: SBT build — Remove dead package-resolver URLs to avoid domain-takeover risk
**Context:** PR #883 — the SBT build still referenced dl.bintray.com, which shut down in 2021, leaving an abandoned domain that could be re-registered to serve malicious artifacts.
**Rule:** Remove resolver/repository URLs for shut-down services from build config, because an abandoned dependency domain can be taken over and used to serve malicious artifacts.

### 2026-11-20: Scala client — Spark profile option keys must match the profile JSON deserializer field names
**Context:** PR #866 — the OAuth profile type Spark option was silently ignored because it used key shareCredentialsType while the profile JSON deserializer reads the field named type.
**Rule:** When exposing a profile field as a Spark option, name the option key to match the profile JSON deserializer's field name, or the supplied value is silently dropped.
